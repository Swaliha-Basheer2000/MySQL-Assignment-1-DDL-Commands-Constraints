# MySQL-Assignment-1-DDL-Commands-Constraints
Project Overview

This assignment focuses on MySQL DDL (Data Definition Language) commands and constraints using an Employee Database.

Topics Covered

Database and table creation (CREATE)

Modifying table structures (ALTER)

Renaming tables (RENAME)

Removing all table records (TRUNCATE)

Dropping tables and databases (DROP)

Applying constraints such as PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK, and AUTO_INCREMENT.
